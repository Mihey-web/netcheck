# netcheck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows-приложение (одно окно, одна кнопка), которое диагностирует доступность интернета по слоям и словами объясняет, почему что-то не работает, особенно при включённом/выключенном VPN.

**Architecture:** Ядро — чистые Go-пакеты (`probe` атомарные тесты, `env` снимок окружения, `analyze` разбор причин, `verdict` сборка вердикта, `runner` оркестрация, `config`, `history`). GUI — Wails v2 (WebView2), фронт vanilla HTML/CSS/JS вшит в бинарь, общается с ядром через биндинги. Логика (`verdict`/`analyze`) не знает про сеть и покрыта табличными тестами; сетевые пакеты изолируют системные вызовы за интерфейсами и тестируются на фикстурах.

**Tech Stack:** Go 1.23+, Wails v2, WebView2 (runtime уже в Windows 10/11), vanilla JS-фронт, `gopkg.in/yaml.v3`, `golang.org/x/net/dns/dnsmessage` (или stdlib), GitHub Actions.

## Global Constraints

- Платформа v1: **windows/amd64**. ICMP — через `IcmpSendEcho` WinAPI (без прав администратора).
- Артефакт — один `netcheck.exe`, фронт вшит через `//go:embed`. Никаких внешних файлов для запуска.
- Слушать сеть/писать файлы: конфиг и история — в `%APPDATA%\netcheck\`. Рядом с exe ничего писать не пытаемся (может лежать в Program Files).
- Языки: RU + EN. Все пользовательские строки — через словарь `msgid → {ru,en}`. Нет хардкода русского/английского в логике; логика возвращает msgid + аргументы.
- Никакой персональщины в коде. Цели/порты — только в дефолтном `config.yaml`.
- Шрифт `space_engineers.ttf` — проприетарный, в репо/сборку НЕ попадает (уже в `.gitignore`). В приложении — свободный аналог под OFL (Orbitron) с fallback `Bahnschrift, "Segoe UI"`.
- Стиль/раскладка UI — по утверждённому мокапу `mockups/netcheck-c-report.html`.
- Таймауты: 3000 мс на отдельный тест, 20000 мс на весь прогон (из конфига).
- Модуль: `github.com/mihey/netcheck` (поправить username при создании репозитория, но это имя используется в путях импортов ниже).

`probe.go`:

```go
package probe

import "time"

type Status string

const (
	StatusOK   Status = "ok"
	StatusWarn Status = "warn"
	StatusFail Status = "fail"
)

type Path string

const (
	PathDirect Path = "direct"
	PathProxy  Path = "proxy"
)

type Result struct {
	Target  string        `json:"target"`
	Method  string        `json:"method"`
	Path    Path          `json:"path"`
	Latency time.Duration `json:"latency"`
	Status  Status        `json:"status"`
	Detail  string        `json:"detail"`
	IPs     []string      `json:"ips,omitempty"`
}

func SameIPSet(a, b []string) bool {
	if len(a) == 0 || len(b) == 0 {
		return false
	}
	set := make(map[string]struct{}, len(a))
	for _, x := range a {
		set[x] = struct{}{}
	}
	for _, y := range b {
		if _, ok := set[y]; ok {
			return true
		}
	}
	return false
}
```

- [ ] **Step 4: Реализовать DNS-пробы**

`dns.go` — `ResolveSystem` через `net.Resolver`; `ResolveUDP` формирует запрос через `golang.org/x/net/dns/dnsmessage` и шлёт UDP на server; `ResolveDoH` — POST application/dns-message на dohURL. Каждая ставит `Method` = "DNS", "DNS·UDP", "DNS·DoH" соответственно, заполняет `IPs`, `Latency`, `Status` (OK если есть ответ, FAIL при ошибке/таймауте), `Detail` при ошибке. Все уважают `ctx` дедлайн.

```go
package probe

import (
	"context"
	"net"
	"time"
)

func ResolveSystem(ctx context.Context, host string) Result {
	start := time.Now()
	r := Result{Target: host, Method: "DNS", Path: PathDirect}
	ips, err := net.DefaultResolver.LookupHost(ctx, host)
	r.Latency = time.Since(start)
	if err != nil {
		r.Status, r.Detail = StatusFail, err.Error()
		return r
	}
	r.IPs, r.Status = onlyIPv4(ips), StatusOK
	return r
}

func onlyIPv4(in []string) []string {
	var out []string
	for _, s := range in {
		if ip := net.ParseIP(s); ip != nil && ip.To4() != nil {
			out = append(out, s)
		}
	}
	return out
}
```
(`ResolveUDP`/`ResolveDoH` реализовать по аналогии с dnsmessage/HTTP; добавить `go get golang.org/x/net`.)
